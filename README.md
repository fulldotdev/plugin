# Fulldev plugin

The Fulldev plugin for Claude, ChatGPT and Codex: the Fulldev connector (`https://app.full.dev/mcp`) and the `fulldev` skill, in [plugins/fulldev](plugins/fulldev). Its README says what it does, what it connects to and how it handles data.

```sh
# Claude Code
/plugin marketplace add fulldotdev/plugin
/plugin install fulldev@fulldev

# Codex, from OpenAI's plugin directory, as in ChatGPT
codex plugin add fulldev@openai-curated-remote
```

In ChatGPT, open **Plugins**, search for Fulldev and click **Install plugin**; Codex signed in to the same account has it too.

This repository is published from Fulldev's own repository on each release; changes made here are overwritten. Questions: [contact@full.dev](mailto:contact@full.dev).
